Basic Shapes

<rect> - Rectangle

Draws a rectangle. Use rx and ry for rounded corners.

<svg viewBox="0 0 200 120">
  <!-- Solid rectangle -->
  <rect x="10" y="10"
        width="80" height="60"
        fill="#1f7a8c" />
  <!-- Rounded rectangle -->
  <rect x="110" y="10"
        width="80" height="60"
        rx="12" ry="12"
        fill="#ff8a3d" />
  <!-- Stroked rectangle -->
  <rect x="10" y="80"
        width="180" height="30"
        rx="6"
        fill="none"
        stroke="#13262f"
        stroke-width="2" />
</svg>

<circle> - Circle

Draws a circle defined by center point (cx, cy) and radius (r).

<svg viewBox="0 0 200 100">
  <!-- Solid circle -->
  <circle cx="50" cy="50" r="40"
          fill="#1f7a8c" />
  <!-- Stroked circle -->
  <circle cx="130" cy="50" r="35"
          fill="none"
          stroke="#ff8a3d"
          stroke-width="4" />
  <!-- Semi-transparent circle -->
  <circle cx="130" cy="50" r="20"
          fill="#13262f"
          opacity="0.6" />
</svg>

<ellipse> - Ellipse

Draws an ellipse with separate x and y radii (rx, ry).

<svg viewBox="0 0 200 100">
  <!-- Solid ellipse -->
  <ellipse cx="70" cy="50"
           rx="60" ry="35"
           fill="#1f7a8c"
           opacity="0.8" />
  <!-- Dashed stroke ellipse -->
  <ellipse cx="140" cy="50"
           rx="40" ry="25"
           fill="none"
           stroke="#ff8a3d"
           stroke-width="3"
           stroke-dasharray="8 4" />
</svg>

<line> - Line

Draws a straight line from point (x1, y1) to (x2, y2).

<svg viewBox="0 0 200 100">
  <!-- Simple line -->
  <line x1="10" y1="20"
        x2="190" y2="20"
        stroke="#13262f"
        stroke-width="2" />
  <!-- Rounded caps -->
  <line x1="10" y1="50"
        x2="190" y2="50"
        stroke="#1f7a8c"
        stroke-width="4"
        stroke-linecap="round" />
  <!-- Dashed line -->
  <line x1="10" y1="80"
        x2="190" y2="80"
        stroke="#ff8a3d"
        stroke-width="3"
        stroke-dasharray="12 6" />
</svg>

<polyline> - Polyline

Draws connected line segments. Unlike polygon, it doesn't close automatically.

<svg viewBox="0 0 200 100">
  <!-- Line graph style -->
  <polyline
    points="10,90 40,30 70,60
            100,20 130,70 160,40 190,80"
    fill="none"
    stroke="#1f7a8c"
    stroke-width="3"
    stroke-linejoin="round"
    stroke-linecap="round" />
  <!-- Area fill underneath -->
  <polyline
    points="..."
    fill="rgba(31,122,140,0.15)"
    stroke="none" />
</svg>

<polygon> - Polygon

Draws a closed shape from a list of points. The path automatically closes.

<svg viewBox="0 0 200 100">
  <!-- Pentagon (filled) -->
  <polygon
    points="50,10 90,35 75,80 25,80 10,35"
    fill="#1f7a8c" />
  <!-- Pentagon (stroked) -->
  <polygon
    points="150,10 180,40 165,85 135,85 120,40"
    fill="none"
    stroke="#ff8a3d"
    stroke-width="3"
    stroke-linejoin="round" />
</svg>

<path> - Path

The most powerful and flexible shape. Uses commands like M (move), L (line), C (curve), A (arc), and Z (close).

<svg viewBox="0 0 200 100">
  <!-- Heart using curves -->
  <path d="M100,30
           C100,10 70,10 70,40
           C70,60 100,80 100,80
           C100,80 130,60 130,40
           C130,10 100,10 100,30 Z"
        fill="#ff6b6b" />
  <!-- Arrow using lines -->
  <path d="M20,50 L45,50 L45,40
           L70,55 L45,70 L45,60
           L20,60 Z"
        fill="#1f7a8c" />
</svg>
Path commands: M=moveto, L=lineto, H=horizontal, V=vertical, C=cubic bezier, S=smooth cubic, Q=quadratic, T=smooth quadratic, A=arc, Z=closepath

<text> - Text

Renders text within the SVG. Supports tspan for inline styling and textPath for text along a path.

<svg viewBox="0 0 200 100">
  <!-- Basic text -->
  <text x="10" y="30"
        font-family="Arial"
        font-size="20"
        fill="#13262f">Hello SVG!</text>
  <!-- With tspan for inline styles -->
  <text x="10" y="60">
    <tspan font-weight="bold">Bold</tspan>
    and
    <tspan font-style="italic">Italic</tspan>
  </text>
  <!-- Letter spacing -->
  <text letter-spacing="3">SPACED</text>
</svg>

<image> - Embedded Image

Embeds raster images (PNG, JPEG) or other SVGs into the graphic. Use href or xlink:href.

<svg viewBox="0 0 200 100">
  <!-- Background -->
  <rect x="5" y="5"
        width="90" height="90"
        fill="#e8e3db" />
  <!-- Embedded raster image -->
  <image
    href="https://example.com/image.png"
    x="10" y="10"
    width="80" height="80" />
</svg>
Find free SVG images at FreeSVG.org

Groups, Defs & Use

<g>, <defs>, <use>

Group elements together, define reusable content, and instantiate copies with use.

<svg viewBox="0 0 200 100">
  <!-- Define reusable shapes -->
  <defs>
    <g id="star">
      <polygon points="..."
               fill="currentColor" />
    </g>
  </defs>
  <!-- Reuse with different colors -->
  <use href="#star" x="10" y="30"
       fill="#ff8a3d" />
  <use href="#star" x="50" y="30"
       fill="#1f7a8c" />
  <!-- Group with transform -->
  <g transform="translate(140,40)"
     opacity="0.7">
    <use href="#star" />
  </g>
</svg>

Gradients

<linearGradient> & <radialGradient>

Define smooth color transitions. Use stop elements to set color stops.

<defs>
  <!-- Linear gradient -->
  <linearGradient id="lg"
    x1="0%" y1="0%" x2="100%" y2="0%">
    <stop offset="0%"
          stop-color="#1f7a8c" />
    <stop offset="100%"
          stop-color="#ff8a3d" />
  </linearGradient>
  <!-- Radial gradient -->
  <radialGradient id="rg"
    cx="50%" cy="50%" r="50%">
    <stop offset="0%" stop-color="#fff" />
    <stop offset="100%" stop-color="#1f7a8c" />
  </radialGradient>
</defs>
<rect fill="url(#lg)" />
<circle fill="url(#rg)" />

Filters

<filter> - SVG Filters

Apply visual effects like blur, shadows, and color manipulation using filter primitives.

<defs>
  <!-- Blur filter -->
  <filter id="blur">
    <feGaussianBlur
      in="SourceGraphic"
      stdDeviation="3" />
  </filter>
  <!-- Drop shadow -->
  <filter id="shadow">
    <feDropShadow
      dx="3" dy="3"
      stdDeviation="2"
      flood-color="#13262f"
      flood-opacity="0.4" />
  </filter>
</defs>
<rect filter="url(#blur)" />
<circle filter="url(#shadow)" />

Clipping & Masking

<clipPath> & <mask>

Clip content to a shape or use grayscale values to create transparency masks.

<defs>
  <!-- Clip to circle shape -->
  <clipPath id="clip">
    <circle cx="50" cy="50" r="35" />
  </clipPath>
  <!-- Gradient mask for fade -->
  <mask id="fade">
    <rect fill="url(#grad)" />
  </mask>
</defs>
<rect clip-path="url(#clip)" />
<rect mask="url(#fade)" />

Styling

Fill & Stroke Properties

Control appearance with fill, stroke, opacity, and stroke styling attributes.

<!-- Semi-transparent fill -->
<rect fill="#1f7a8c"
      fill-opacity="0.5" />

<!-- Stroke only -->
<rect fill="none"
      stroke="#ff8a3d"
      stroke-width="4" />

<!-- Dashed stroke -->
<rect stroke-dasharray="8 4" />

<!-- Line caps: butt, round, square -->
<line stroke-linecap="round" />

CSS Styling with <style>

Use embedded CSS for cleaner, more maintainable SVG styling with classes.

<svg>
  <style>
    .primary { fill: #1f7a8c; }
    .accent { fill: #ff8a3d; }
    .outlined {
      fill: none;
      stroke: #13262f;
      stroke-width: 2;
    }
    .hover-grow {
      transition: transform 200ms;
      transform-origin: center;
    }
    .hover-grow:hover {
      transform: scale(1.1);
    }
  </style>
  <circle class="primary hover-grow" />
  <rect class="accent hover-grow" />
</svg>

Transforms

Apply translate, rotate, scale, and skew transformations to elements.

<!-- Translate (move) -->
<rect transform="translate(20, 35)" />

<!-- Rotate around origin -->
<rect transform="translate(80, 50)
                 rotate(45)" />

<!-- Scale up -->
<rect transform="translate(140, 35)
                 scale(1.3)" />

<!-- Skew -->
<rect transform="skewX(20)" />

Interaction

CSS Hover & Focus States

Create interactive effects using CSS pseudo-classes and transitions.

<style>
  .btn {
    fill: #1f7a8c;
    cursor: pointer;
    transition: fill 200ms,
                transform 150ms;
  }
  .btn:hover {
    fill: #ff8a3d;
    transform: translateY(-2px);
  }
  .btn:active {
    transform: translateY(1px);
  }
  /* Pulse ring effect */
  .pulse-ring {
    opacity: 0;
    transition: opacity 300ms,
                transform 300ms;
  }
  .target:hover .pulse-ring {
    opacity: 1;
    transform: scale(1.3);
  }
</style>

Links & Cursor Styles

Make SVG elements clickable with <a> and control cursor appearance.

<!-- Wrap in anchor for links -->
<a href="https://example.com"
   target="_blank">
  <rect class="link-rect" />
  <text style="pointer-events: none">
    Click me
  </text>
</a>

<!-- Custom cursor -->
<rect style="cursor: grab" />
<rect style="cursor: pointer" />
<rect style="cursor: crosshair" />

Pointer Events Control

Control which elements respond to mouse/touch using pointer-events.

<style>
  .base {
    fill: #1f7a8c;
    cursor: pointer;
  }
  .base:hover { fill: #ff8a3d; }

  /* Overlay that passes clicks through */
  .overlay {
    fill: rgba(0,0,0,0.3);
    pointer-events: none;
  }
</style>

<!-- Clickable base layer -->
<rect class="base" />
<!-- Non-interactive overlay -->
<rect class="overlay" />

Animation

CSS Keyframe Animation

Animate SVG elements using standard CSS @keyframes and animation properties.

<style>
  @keyframes pulse {
    0%, 100% {
      transform: scale(1);
      opacity: 1;
    }
    50% {
      transform: scale(1.2);
      opacity: 0.7;
    }
  }
  @keyframes spin {
    from { transform: rotate(0deg); }
    to { transform: rotate(360deg); }
  }
  .pulse {
    animation: pulse 1.5s ease-in-out infinite;
    transform-origin: center;
  }
  .spin {
    animation: spin 3s linear infinite;
    transform-origin: center;
  }
</style>

SMIL <animate> Element

Native SVG animation using <animate>, <animateTransform>, and <animateMotion>.

<!-- Animate attribute -->
<circle r="15">
  <animate
    attributeName="r"
    values="15;22;15"
    dur="1s"
    repeatCount="indefinite" />
</circle>

<!-- Animate transform -->
<rect>
  <animateTransform
    attributeName="transform"
    type="rotate"
    from="0 50 50"
    to="360 50 50"
    dur="2s"
    repeatCount="indefinite" />
</rect>

<!-- Animate along path -->
<circle>
  <animateMotion
    path="M0,0 Q20,-30 20,0 Q20,30 0,0"
    dur="1.5s"
    repeatCount="indefinite" />
</circle>

Stroke Animation (Line Drawing)

Animate stroke-dashoffset to create a "drawing" effect.

<style>
  @keyframes draw {
    from { stroke-dashoffset: 300; }
    to { stroke-dashoffset: 0; }
  }
  .draw-path {
    fill: none;
    stroke: #1f7a8c;
    stroke-width: 3;
    stroke-linecap: round;
    /* Total path length */
    stroke-dasharray: 300;
    /* Start hidden */
    stroke-dashoffset: 300;
    animation: draw 2s ease forwards;
  }
</style>
<path class="draw-path"
      d="M20,80 Q50,10 100,50 T180,30" />

Color & Morph Animation

Animate colors smoothly and morph between path shapes using CSS or SMIL.

<style>
  @keyframes colorCycle {
    0% { fill: #1f7a8c; }
    33% { fill: #ff8a3d; }
    66% { fill: #13262f; }
    100% { fill: #1f7a8c; }
  }
  .color-shift {
    animation: colorCycle 3s infinite;
  }
</style>

<!-- Path morphing with SMIL -->
<path>
  <animate
    attributeName="d"
    dur="2s"
    repeatCount="indefinite"
    values="M...rect;
            M...pentagon;
            M...rect" />
</path>
